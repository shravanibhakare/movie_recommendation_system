# 🎬 Movie Recommender System

A simple **Movie Recommendation System** built with **Streamlit**.  
This app suggests movies similar to the one you enter, along with:  
- 🎥 YouTube trailers  
- 📖 Wikipedia links for more details  

👉 **[Live Demo](https://movierecommendationsystem-2efy94gjsfqvsjerw2qwui.streamlit.app/)** 
---

## 🚀 Features
- Search or select a movie from the dataset  
- Get **top 5 closest matches** using string similarity (`difflib`)  
- Watch trailers directly on YouTube  
- Explore Wikipedia pages of recommended movies  
- Clean and interactive UI powered by Streamlit
